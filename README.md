# PC Keyboard

A full PC keyboard (Esc, F1–F12, Ctrl, Alt, Win, arrows, Home/End, PgUp/PgDn) that floats over every app on your phone and sends real key presses, so it works in games, emulators and remote-desktop apps, not just text boxes.

It uses [Shizuku](https://shizuku.rikka.app/) to press keys the same way a USB or Bluetooth keyboard would. No root needed.

## Setup
1. Install Shizuku from the Play Store.
2. Start Shizuku with "Start via Wireless debugging" (again after each phone restart).
3. Open PC Keyboard, allow it in Shizuku, and allow "Display over other apps".
4. Tap **Show keyboard**.

GitHub Actions builds the APK on every push and publishes it on the Releases page.
